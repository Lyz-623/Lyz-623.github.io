# Homepage fonts

Unmodified font files distributed by Google Fonts, downloaded on 2026-09-10.
Both families use the SIL Open Font License 1.1; license notices are included here.

- Newsreader (normal, variable TTF): https://raw.githubusercontent.com/google/fonts/main/ofl/newsreader/Newsreader%5Bopsz%2Cwght%5D.ttf
- Source Sans 3 (normal, variable): https://fonts.gstatic.com/s/sourcesans3/v19/nwpStKy2OAdR1K-IwhWudF-R3w8aZQ.woff2
- Source Sans 3 (italic, variable TTF): https://raw.githubusercontent.com/google/fonts/main/ofl/sourcesans3/SourceSans3-Italic%5Bwght%5D.ttf

Self-hosted to keep typography consistent when Google Fonts is unavailable.
The normal Source Sans 3 file is a Latin subset; other characters use the system fallback stack.
